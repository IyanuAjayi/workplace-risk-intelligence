05 /Chart conventions
ROC curve, 2023 test: scorecard and rating class only
Axes

1px Onyx baseline. No value axis when every mark is labelled.

Gridlines

1px hairline, solid, only where values are read off.

Labels

Value at the bar end. Lines: end labels only.

Annotation

One per chart: italic figure, mono working.

Highlight

Screen ink for the key series, #A7B6A5 for the rest.

Reference

1px Onyx line with a mono label.
